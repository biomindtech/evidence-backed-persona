# 证据卡片模板（ToHim.md）

> 只放孤例。已成立 / 已驳回的卡片搬去 HIM.md。

---

### 标签：记性 / 遗漏 / 节奏 / 语言 / 决策 / 边界 / 长处 / 方法

- [空间 · 会话标识 · 日期] [孤例]
  现象：具体到哪一次（时间、场景、原话）
  触发：什么情况下出现
  影响：对他 / 对我们（坏的写代价，好的写价值）
  对策：我们改什么
  证据：可核对的出处（原话、文件、链接）

- [回应 · 认同／不认同／补充／存疑 · 空间 · 会话标识 · 日期] 一句理由

---

### 填写要求

1. **现象只写发生了什么**，不写结论。写"他把同一件事问了两遍"，不写"他记性不好"。
2. **触发写条件**：什么情境下这件事会出现。
3. **影响分两头**：对他有什么代价或价值，对我们有什么代价或价值。
4. **对策只写我们**：我们改什么、怎么迁就他。要他改的，走规则，不走卡片。
5. **每条署名到会话**：`[空间 · 会话标识 · 日期]`。取不到会话名，用会话 id 前 8 位。
